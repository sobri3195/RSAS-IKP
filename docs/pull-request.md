## RSAS-SAFETY: frontend pelaporan insiden dan manajemen risiko

Mengubah alur formulir kertas menjadi prototipe React/TypeScript frontend-only untuk RSAU Prof. dr. Abdulrachman Saleh. Menyediakan dashboard berbasis 15 data sintetis, wizard delapan langkah dengan 14 butir, penyimpanan dan validasi lokal, workflow verifikasi, grading manual, RCA, CAPA, analitik, laporan mutu, serta cetak A4 berwatermark DEMO.

Semua role, paraf, timestamp, dan notifikasi adalah simulasi. Tidak untuk data pasien nyata. Matriks SOP resmi belum dikonfigurasi sehingga tidak ada skor risiko otomatis. Pemetaan regulasi memerlukan review institusi.

Konfigurasi Vercel SPA tersedia; belum dilakukan deployment.

Validasi: `npm run test`, `npm run test:e2e`, dan `npm run build` (lihat laporan akhir untuk hasil aktual).
